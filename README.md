# SwiftUI Calculator Application

## Overview

This project is a simple **iOS Calculator application** built using SwiftUI. The application demonstrates the implementation of basic arithmetic operations within a clean and responsive mobile interface.

The goal of this project is to practice iOS development concepts such as SwiftUI views, application structure, and separating logic using a model-based architecture.

## Features

* Perform basic arithmetic operations
* Responsive calculator interface
* Clean and simple UI built with SwiftUI
* Separation between UI and calculation logic
* Real-time display of calculations

## Technologies Used

* Swift
* SwiftUI
* Xcode
* iOS SDK

## Installation & Setup

1. Open **Xcode**
2. Select **Open a project or file**
3. Navigate to the project folder
4. Open:

```
calculator.xcodeproj
```

5. Select an **iOS Simulator** or connected device
6. Press **Run ▶** to launch the calculator application

## Learning Objectives

This project demonstrates:

* Building user interfaces with SwiftUI
* Implementing application logic with a model
* Structuring an iOS project using MVC-style organization
* Handling user input through interactive buttons
